# Privacy Policy — LogicDevSupport YouTube Uploader

Last updated: 2026-10-24

This privacy policy describes the Google Cloud project "LogicDevSupport" (YouTube Data API v3), an internal tool operated by LogicDevSupport.

## What the tool does
The tool is used only by LogicDevSupport to upload and manage videos on LogicDevSupport's own YouTube channel (https://www.youtube.com/@LogicDevSupport): uploading promotional videos of our assets, setting titles, descriptions and tags, and adding videos to playlists.

## Data we access
- The tool signs in only with LogicDevSupport's own Google account.
- It accesses only that account's YouTube channel data needed for the tasks above (the channel's videos and playlists).
- It does not access, collect, or store data of any other user.

## Data we store
- A sign-in token for our own account is stored only on our own computer, so that uploads do not require signing in every time.
- No personal data of other people is collected, stored, sold, or shared.

## Third parties
Video data is sent only to YouTube (Google) through the YouTube Data API. YouTube's own terms and Google's privacy policy apply: https://www.youtube.com/t/terms , https://policies.google.com/privacy

## Revoking access
The account owner can remove the tool's access at any time at https://myaccount.google.com/permissions

## Contact
logic.dev.support@gmail.com

## プライバシーポリシー（日本語）

このページは、LogicDevSupport が運用する社内用ツール（Google Cloud のプロジェクト「LogicDevSupport」、YouTube Data API v3）のプライバシーポリシーです。

- **用途**: LogicDevSupport 自身の YouTube チャンネル（https://www.youtube.com/@LogicDevSupport ）に、当方のアセットの紹介動画を上げ、タイトル・説明・タグ・再生リストを設定するためだけに使います。

- **保存するもの**: 毎回サインインしなくて済むよう、当方のアカウントのサインイン情報を当方のパソコンにのみ保存します。ほかの方の個人情報を集めたり、売ったり、共有したりすることはありません。
- **第三者**: 動画のデータは YouTube Data API を通じて YouTube（Google）にのみ送ります。YouTube の利用規約と Google のプライバシーポリシーが適用されます。
- **アクセスの取り消し**: https://myaccount.google.com/permissions からいつでも取り消せます。
- **連絡先**: logic.dev.support@gmail.com
